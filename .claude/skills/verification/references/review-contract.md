# Verification review contract

## Verdict
PASS | FAIL | INSUFFICIENT EVIDENCE

## Acceptance criteria
For each criterion: criterion, evidence, result.

## Command evidence
List required checks, timestamps, exit results, and whether any became stale after subsequent edits.

## Gaps
Missing behavioral, migration, rollback, security, compatibility, or operational proof.

## Required next action
Only the smallest concrete repair or verification action. Do not perform it inside the verifier role.
