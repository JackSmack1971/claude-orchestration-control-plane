# Research methodology

For one research question:

1. State the exact factual question.
2. Identify what evidence would answer it.
3. Inspect repository/primary evidence first.
4. For version-sensitive external facts, prefer authoritative current sources.
5. Record concrete evidence references.
6. Record contradictions without silently reconciling them.
7. Separate observed evidence from inference.
8. Assign confidence: `high`, `medium`, or `low`.
9. Record unknowns.
10. State only evidence-supported implications for the plan.

Read `${CLAUDE_SKILL_DIR}/references/output-contract.md` and return that structure. Research never writes or repairs an implementation plan.
